    - launch a `robot_state_publisher`, in charge of publishing the coordinate frames of each link.

- **Hint** &rarr; In order to create a message of type `JointState` in C++, the following lines of code can be used:
```
auto message  = sensor_msgs::msg::JointState();
rclcpp::Time now = this->get_clock()->now();
message.header.stamp = now;
message.name = {"joint_name_1","joint_name_2"}; // Check joint names in the urdf file
message.position = {q0,q1};
```

### Answers

#### 1. Explain what the nodes launched in `launch/simple_visualizer.py` file do.

1. `tf2_ros`:
   - This node sets a relation between two coordinate frames: `odom` and `axis`.  
    We added this node to the launchfile so the robot's base (`axis` frame) is localated at a specific position and orientation relative to the world (`odom` frame).

2. `robot_state_publisher`:  
   - This node reads the **URDF file** and uses it to publish the coordinate frames (links and joints) of the robot.  
    This node is essential if we want to visualize the robot in RViz because it dynamically updates the positions of the robot's parts based on the joint angles. Without this node, RViz wouldn't know how to position or orient the robot's links.

3. `joint_pub`:  
   - This is my own custom node that takes joint angles (positions) from the topic `/q` and publishes them as `JointState` messages to the topic `/joint_states`.  

4. `rviz2`:  
   - This is the graphical tool we use to diplay the robot in a 3D environment.  
    I added this node to the launch file so we don't need another terminal for Rviz.


#### 2. Write here the instructions to demonstrate the functionality of the developed solutions:

1. **Terminal 1**: Launch the core system (trajectory generator, controller, kinematic model, simulator, disturbance generator).  
   ```bash
   source install/setup.bash
   ros2 launch ros2_planar_robot ros2_planar_robot_launch.py
   ```
   *This terminal starts the robot simulation and control system.*

2. **Terminal 2**: Launch the visualization tools (RViz, robot state publisher, static transform, and joint publisher).  
   ```bash
   source install/setup.bash
   ros2 launch ros2_planar_robot simple_visualizer.py
   ```
   *This terminal starts all the visualization components needed for RViz.*

1. **Terminal 3**: Run the high-level manager to provide trajectories.  
   ```bash
   source install/setup.bash
   ros2 run ros2_planar_robot high_lev_mng
   ```
   *This terminal lets you input the trajectory points for the robot. Select the number and the different position you wish to reach.*

2. **Terminal 4**: Set the `launch` flag to `true` to start the simulation.  
   ```bash
   source install/setup.bash
   ros2 topic pub -1 /launch std_msgs/msg/Bool "{data: true}" --once
   ```
   *This terminal launch the robot.*
